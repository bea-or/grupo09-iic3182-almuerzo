# ¿Dónde almuerzo hoy? 🍽️

Página web para que estudiantes de la UC decidan **qué y dónde almorzar en el campus San Joaquín** antes de caminar hasta el local: qué opciones hay dentro y fuera del campus, qué vende cada una, cuánto cuesta, su horario y cómo se compra.

🔗 **Ver la página:** https://bea-or.github.io/grupo09-iic3182-almuerzo/


## Fuentes de los datos

- Entrevistas a cinco estudiantes (Entrega 1, octubre de 2026).
- Guía de servicios de alimentación del campus San Joaquín (UC, 2020).
- Observación del grupo.
